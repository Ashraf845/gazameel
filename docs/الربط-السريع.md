# الربط السريع — واجباتك الثلاث

الكود والدروس جاهزة. ما يتبقى **لصق مفاتيح حقيقية** من حساباتك.

```bash
cd ~/Projects/gazameel
cp -n .env.example .env.local   # إن لم يكن موجودًا
npm run check:setup             # يبيّن ما ينقص بدون كشف الأسرار
```

---

## 1) Supabase (مرحلة 1) — إلزامي

الدليل التفصيلي: [درس-المرحلة-1.md](./درس-المرحلة-1.md)

1. أنشئ مشروعًا على [supabase.com](https://supabase.com)
2. SQL Editor → نفّذ `supabase/schema.sql` ثم `supabase/rls.sql`
3. Storage → bucket اسمه **`resources`** (Private) — راجع `supabase/STORAGE.md`
4. Auth → Google → فعّل + Redirect: `{APP_URL}/api/auth/callback`
5. الصق في `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `ADMIN_EMAIL` = بريد Google تبعك
6. `npm run dev` → اختبر Checklist في درس المرحلة 1

عند النجاح يختفي شريط «معاينة بدون قاعدة بيانات» من الصفحة الرئيسية.

---

## 2) تيليجرام (مرحلة 2) — بعد نجاح الويب

الدليل: [درس-المرحلة-2.md](./درس-المرحلة-2.md)

1. @BotFather → توكن + username
2. اعرف `chat_id` → `ADMIN_TELEGRAM_CHAT_ID`
3. املأ في `.env.local` ثم بعد النشر:

```bash
curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://YOUR_DOMAIN/api/telegram/webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>"
```
