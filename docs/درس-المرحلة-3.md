# درس المرحلة 3 — مجتمع (مساهمون + استطلاعات + تقدم + واتساب)

> بعد مرحلتي 1 و 2. الكود جاهز؛ معظمها يعتمد على بيانات حقيقية من Supabase.

## ماذا تغطي؟

| القدرة | المسار | المصدر |
|--------|--------|--------|
| قائمة المساهمين | `/contributors` | تجميع `resources` المعتمدة |
| استطلاعات | `/polls` + تبويب أدمن | `polls` / `poll_votes` |
| تقدم الطالب | `/progress` | `quiz_attempts` |
| واتساب | `/about` + Footer | `NEXT_PUBLIC_WHATSAPP_URL` |
| ربط تيليجرام (مجتمع) | `/telegram` | موجود من المرحلة 2 |

بدون مفاتيح: Banner أو رسالة إعداد — لا قوائم فارغة صامتة مضلّلة.

---

## 1) واتساب (دقيقتان)

1. أنشئ مجموعة واتساب للدفعة (أو رابط دعوة).
2. في `.env.local`:

```text
NEXT_PUBLIC_WHATSAPP_URL=https://chat.whatsapp.com/XXXX
```

3. أعد تشغيل الخادم.
4. يظهر الرابط في `/about` وفي **التذييل** تلقائيًا.

لا أتمتة واتساب في MVP — رابط يدوي فقط (حسب الخطة).

---

## 2) المساهمون

- الصفحة: `src/app/contributors/page.tsx`
- تعدّ الملفات `approved` وتجمع حسب اسم المساهم.
- بعد اعتماد ملفات من الأدمن ستمتلئ القائمة.

---

## 3) الاستطلاعات

1. أدمن → تبويب **استطلاعات** → سؤال + خيارات (سطر لكل خيار).
2. الطلاب يصوّتون من `/polls` (يلزم تسجيل دخول للتصويت).
3. API: `GET/POST /api/polls` — إن نقصت المفاتيح يرجع 503 برسالة عربية.

---

## 4) التقدم

- `/progress` يعرض أفضل نسبة وآخر محاولة لكل مادة.
- يحتاج محاولات من `/quiz` أولًا.

---

## 5) Checklist المرحلة 3

1. ☐ ضع رابط واتساب → يظهر في Footer و About.
2. ☐ اعتمد ملفين بأسماء مساهمين مختلفة → `/contributors` يعرضهم.
3. ☐ أنشئ استطلاعًا → صوّت → النسب تتحدّث.
4. ☐ أكمل كويزًا → `/progress` يعرض النسبة.

---

## ترتيب التعلم المقترح للملفات

1. `src/app/about/page.tsx` + `components/Footer.tsx` — أين يظهر واتساب؟
2. `contributors/page.tsx` — كيف تُحسب المساهمات من DB؟
3. `api/polls/route.ts` — create للأدمن / vote للطالب.
4. `progress/page.tsx` — قراءة `quiz_attempts`.
