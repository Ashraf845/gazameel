فكرة مشروع Gazameel


المفهوم


منصة تعليمية تفاعلية لطلاب كلية الهندسة وتكنولوجيا المعلومات — الجامعة الإسلامية.

تجمع المصادر الدراسية (ملخصات، سنوات، اختبارات) مع بوت تيليجرام للتنبيهات ومجموعة واتساب للتواصل.


**اسم العلامة:** Gazameel (دمج Gaza + زميل)

**الشعار:** Everything a student needs, in one place. / كل ما يحتاجه الطالب، في مكان واحد.


تنويه


هذا الموقع منصة طلابية غير رسمية، تم تطويرها بمبادرة فردية لخدمة الطلاب وتبادل المصادر الأكاديمية، ولا تتبع تقنيًا أو إداريًا لإدارة الجامعة.


المكونات الرئيسية


1) الموقع

  • تسجيل طالب (Google + رقم جامعي + مواد)
  • مكتبة أكاديمية حسب المادة
  • رفع ملفات من الطلاب بحالة pending ثم موافقة الأدمن
  • تقويم امتحانات من الأدمن فقط
  • Dark mode مناسب للمذاكرة
  • شريط آخر التحديثات

    • 2) بوت تيليجرام (مرحلة لاحقة)

  • تذكيرات قبل الامتحان
  • إشعار الأدمن عند رفع ملف مع أزرار موافقة / رفض
  • سؤال اليوم وعد تنازلي

    • 3) مجتمع واتساب

  • رابط مجموعة للإعلانات السريعة (بدون API في البداية)

    • Content Moderation


    الطالب يرفع من /upload → pending → الأدمن يوافق أو يرفض من الويب (ثم تيليجرام).

    لا يُنشر شيء في المكتبة إلا بعد الاعتماد.

    أسئلة الاختبارات يدخلها الأدمن فقط.


    التقنية


  • Next.js (واجهة عربية RTL)
  • Supabase (Auth Google، Postgres، Storage خاص)
  • نشر مقترح: Vercel + Free Tier
  • مسار المشروع المحلي: /Users/ashraf/Projects/gazameel

    • مراحل التنفيذ


    1. ويب + moderation أساسي + تقويم

    2. تيليجرام محصّن + كويز + تذكيرات

    3. مجتمع وتحليلات بسيطة
