## 1) إنشاء البوت (BotFather)

1. افتح تيليجرام → ابحث `@BotFather`.
2. `/newbot` → اختر اسمًا واسم مستخدم ينتهي بـ `bot`.
3. انسخ **التوكن** → الصقه في `.env.local`:

```text
TELEGRAM_BOT_TOKEN=123456:ABC...
NEXT_PUBLIC_TELEGRAM_BOT_USERNAME=YourBotName
```

(بدون `@` في اسم المستخدم.)

4. اعرف `chat_id` الخاص بك (راسل `@userinfobot` أو أي بوت يعرض رقمك):

```text
ADMIN_TELEGRAM_CHAT_ID=123456789
```

5. (مستحسن على الإنتاج) ضع سرًا عشوائيًا:

```text
TELEGRAM_WEBHOOK_SECRET=سلسلة_عشوائية_طويلة
```

---

## 2) تأمين الأزرار — ماذا يفعل الكود؟

في `handleTelegramUpdate`:

1. إن لم يكن `TELEGRAM_BOT_TOKEN` حقيقيًا → لا يفعل شيء.
2. عند ضغط زر موافقة/رفض: يقارن `from.id` مع `ADMIN_TELEGRAM_CHAT_ID` فقط.
3. يستدعي `reviewResource` الذي يقبل الانتقال **مرة واحدة** من `pending` (idempotency).
4. عند الموافقة ينقل الملف من `pending/` إلى `approved/` إن أمكن.
5. يعدّل رسالة التيليجرام لإزالة الأزرار.

الـ webhook في `api/telegram/webhook/route.ts` يتحقق من ترويسة:

`x-telegram-bot-api-secret-token` = `TELEGRAM_WEBHOOK_SECRET`

محليًا بدون السرّ يُسمح في غير الإنتاج؛ على Vercel عيّن السرّ دائمًا.

---

## 3) ربط Webhook بعد النشر

بعد رفع الموقع على Vercel:

```bash
curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://YOUR_DOMAIN/api/telegram/webhook&secret_token=YOUR_WEBHOOK_SECRET"
```

أو استخدم السكربت:

```bash
npm run check:phase2           # جاهزية البيئة بدون طباعة أسرار
npm run telegram:webhook:set   # setWebhook + secret_token من .env.local
npm run telegram:webhook:info
npm run telegram:me
```

يتطلب `NEXT_PUBLIC_APP_URL=https://YOUR_DOMAIN` (ليس localhost).

## 4) كويز الويب — كيف تختبر؟

1. ادخل كأدمن → `/admin` → أسئلة → أضف سؤالًا أو ارفع [`sample-questions.csv`](./sample-questions.csv) (رموز مواد حقيقية مثل ECOM2402؛ نسخة للتحميل من `/sample-questions.csv`).
2. `/quiz` → اختر مادة → ابدأ → أجب → صحّح.
3. `/progress` يعرض أفضل/آخر نتيجة من `quiz_attempts`.

بدون Supabase: رسائل 503 ودّية، لا انهيار.

---

## 5) التذكيرات (Cron)

- الملف: `api/cron/reminders/route.ts`
- `vercel.json` يستدعيه كل ساعة (`0 * * * *`).
- يتطلب `Authorization: Bearer CRON_SECRET` — يرفض إن كان فارغًا أو `change-me`.
- على Vercel: ضع نفس `CRON_SECRET` في Environment Variables؛ المنصة ترسل الترويسة تلقائيًا للـ Cron.
- بدون بوت أو بدون طلاب مربوطين → `{ sent: 0 }`.

### نشر سريع (إن لم يكن مربوطًا)

```bash
npx vercel login
npx vercel              # معاينة
npx vercel --prod       # إنتاج
# ثم انسخ رابط HTTPS إلى NEXT_PUBLIC_APP_URL في Vercel + .env.local
npm run telegram:webhook:set
```

الطالب يربط تيليجرام من `/telegram` حتى يصل التذكير لـ `telegram_chat_id`.
