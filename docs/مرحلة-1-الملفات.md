## تشغيل المعاينة

```bash
export PATH="$HOME/.local/node20/bin:$PATH"   # إن وُجد
cd ~/Projects/gazameel
npm install   # مرة واحدة
npm run dev
```

افتح الرابط الذي تطبعه الطرفية (مثل `http://127.0.0.1:3000`).

بدون مفاتيح في `.env.local`: الموقع يعمل بمعاينة + رسائل إعداد — لا يتعطل.

## APIs

| مسار | وظيفة |
|------|--------|
| `POST /api/upload` | مساهمة طالب → pending |
| `GET/POST /api/admin/submissions` | طابور + موافقة/رفض |
| `POST /api/admin/resources` | رفع أدمن فوري |
| `POST /api/admin/exams` | موعد امتحان |
| `POST /api/onboarding` | حفظ الرقم الجامعي |
| `GET /api/resources/[id]/download` | Signed URL |
| `GET /api/auth/callback` | رجوع Google OAuth |

## قاعدة البيانات (ما تلصقه أنت)

1. أنشئ مشروع Supabase
2. نفّذ `supabase/schema.sql` ثم `supabase/rls.sql`
3. Storage bucket اسمه `resources` (Private) — انظر `supabase/STORAGE.md`
4. فعّل Google Auth + Redirect URL
5. الصق المفاتيح في `.env.local` (الملف جاهز بـ placeholders عربية)

## ماذا تلصق في `.env.local`؟

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `ADMIN_EMAIL` = إيميلك على Google
